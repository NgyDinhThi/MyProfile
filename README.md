### Featured Projects

#### BIM Sync Manager
Real-time integration system connecting Autodesk Revit with web platforms.
- Sends model data from Revit to the web over **WebSockets**
- Displays 3D models in the browser with **Google Model-Viewer**
- **Stack:** C# · .NET · Revit API · WebSockets

#### Block Adventure
Casual puzzle game built in Unity.
- Object Pooling to keep gameplay smooth
- Code organized around SOLID principles
- **Stack:** Unity · C#

#### Green Ninja
Top-down action game with a quest system.

- **Stack:** Unity · C#
